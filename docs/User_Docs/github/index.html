How to guide

💼 Title

How to create a New gitHub repository through Web UI

📂Context

Why should we have a github account and what is the use of Github repository ? Having a GitHub account is worth it as it enables you to host, manage, and collaborate on files or code projects with an advanced version control system.You can monitor changes made to your code over time, making it a great way to share your work, contribute to open-source code, and demonstrate your coding capability particularly those in the field of software development. Once the github account is created you need to have a github repository to upload your files and code projects.

👥Target Audience

Technical Writers and software developers who wants to show case their work and contribute to open source.

📝Steps

  1. In the upper right corner Click on New on the GitHub homepage.

  1. Enter a name for your repository.

  1. Based on your requirement choose the visibility as Public or Private.

  1. It is Optional to Add a README file to initialize the repository.
tip

The benifit of having a readme file is that if you have one you can add description about repository .

  1. In the last step click on Create Repository.

  1. Your new repository (SampleRepo) is now created with the specified settings.
