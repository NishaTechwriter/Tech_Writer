1. Introduction

This doc contains technical requirements and specifications for 2 important modules of Hotel Booking Website which are Signup and login form .It will ensure that users can create an account, log in to their account and access to their personalized features like Offer coupons and history.

2. Scope

The important specifications that it will cover are :

  • Different Fields required
  • No of tables required
  • Relationship between tables
  • Validation of data

3. Requirements

3.1 Sign-Up Form​

The Sign-Up form allows new users to register on the website by providing their details.

Fields Required:

  • User id
  • Name
  • Email Address
  • Mobile Number
  • Password

3.2 Login Form​

The Login form authenticates existing users to access their accounts.

Fields Required

  • user_id
  • Password

Functionalities:

1)Authentication

  • Verify user credentials against the database.
  • Handle incorrect user_id or password errors.

2)User Feedback

  • Error message for incorrect credentials.
  • Success message upon successful login.

3.3 Additional Features​

  • “Remember Me” checkbox for saving user sessions.
  • “Forgot Password?” link to reset the password via email verification.
  • Redirect to the dashboard upon successful login.

4. Database Schema

There will be requirenment of 2 tables one to store user data and the other to store unique passwords .

Table Name: users

Table Name: Password

5. Validation Rules

  • Validate inputs before storing or checking data in the database.

6. Database

  • MySQL is the most popular database and can be used .

7. Deliverables

  • Sign-Up and Login forms module.
